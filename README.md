# Recherche stage énergie

Outil personnel d'aide à la recherche de stage de fin d'études (PFE) dans le domaine de l'énergie en France.

## Objectif

- Récupérer les offres de stage en énergie via l'API « Offres d'emploi » de France Travail
- Classer les offres selon un profil personnel (formation, compétences, projets)
- Préparer des brouillons de lettres de motivation, relus et envoyés manuellement

## Usage

Projet individuel, non commercial. Les offres ne sont pas republiées : elles sont consultées uniquement par l'auteure pour sa propre recherche de stage.

## Technologies

- Python
- API Offres d'emploi (France Travail)
